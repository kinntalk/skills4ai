# AGENTS.md - Workflow Skills Context

## 🎯 Workflow Skills Persona
- **Role**: Orchestrate development workflow from ideation to completion
- **Skills**: brainstorming, writing-plans, executing-plans, systematic-debugging, test-driven-development, subagent-driven-development
- **Usage Pattern**: Sequential workflow with checkpoints

## 📋 Workflow Sequence
1. **brainstorming**: Explore requirements and design
2. **writing-plans**: Create implementation plan
3. **executing-plans**: Execute with subagent delegation
4. **systematic-debugging**: Debug any issues
5. **test-driven-development**: Write tests before code
6. **subagent-driven-development**: Delegate parallel tasks to subagents

## 🚫 Workflow Boundaries
- **NEVER** skip brainstorming for creative work
- **ALWAYS** use test-driven-development for new features
- **USE** subagent-driven-development for parallel tasks
